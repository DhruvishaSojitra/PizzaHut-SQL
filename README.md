# PizzaHut-SQL
Pizza Restaurant Sales Analysis | MySQL

Analyzed pizza sales data using MySQL to evaluate revenue trends, product performance, category contribution, and hourly ordering patterns.
Used Joins, Subqueries, Aggregate Functions, and Window Functions to extract and analyze business insights.
Identified top-selling products, highest-revenue categories, peak ordering hours, and revenue contribution by category.
Performed time-based analysis using SQL date/time functions to identify daily, monthly, and hourly sales trends.
Created ranking and comparative analyses using RANK() and DENSE_RANK() to evaluate product and category performance.
Generated insights to support inventory planning, menu optimization, promotional decisions, and operational planning.
